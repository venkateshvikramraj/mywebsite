# Vikramraj Venkatesh — Resume Website

A responsive, single-page resume website built with plain HTML, CSS and JavaScript.

## Preview locally
1. Unzip this folder.
2. Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository (for example `vikramraj-portfolio`).
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder if present.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the published URL shown in the Pages section.

## Before publishing
- Replace the LinkedIn placeholder in `index.html` with your actual LinkedIn profile URL.
- The source resume lists New York and Bangalore as locations; review whether you want both shown publicly.
- Confirm the phone number and email are suitable for public display.
- The Yale University Business Negotiations credential is mentioned in the resume's Areas of Expertise. It is displayed as a referenced certification item; verify the exact certificate title and details before publishing.
- The site does not currently include a downloadable PDF button. You can add a public resume PDF link if you want one.
- The hero artwork is the custom green global cybersecurity network graphic in `assets/global-cybersecurity-network.png`.

No build tools or frameworks are required.
